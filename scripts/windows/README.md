# Windows Helper Scripts

These are optional helper launchers kept out of the project root so the main folder stays navigable.

- `run_calibrate.bat` - run simulator/deck calibration tooling.
- `run_dry_preflight.bat` - validate a start request without launching a real career.
- `run_dual_sweepy.bat` - launch dual-instance Sweepy.
- `run_smoke_tests.bat` - run the smoke test suite.

Primary launchers remain in the project root:

- `setup_and_run_sweepy.bat`
- `run_sweepy.bat`
- `optimizer.bat`
